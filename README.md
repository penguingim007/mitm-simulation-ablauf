# MitM-Angriff: Ablauf und Eingriff

Öffentliche, schrittweise Lernsimulation: https://penguingim007.github.io/mitm-simulation-ablauf/

Die Simulation führt durch Anfrage, Abfangen, Eingriff und Weiterleitung. Sie vergleicht HTTP mit HTTPS/TLS und sendet keine Daten. Alle Nachrichten und Eingriffe sind beispielhaft.

## Lokal öffnen

`index.html` in einem aktuellen Browser öffnen.
